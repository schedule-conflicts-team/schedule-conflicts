# Публикация расписания полным снимком

Решение принял Евгений Полыковский 14.11.2026. Запись оформлена 21.11.2026 по описанию архитектуры и задаче на диаграмму.

## Решение

Подготовка, проверка конфликтов и согласование расписания остаются в 1С. После одобрения 1С отправляет в FastAPI полный снимок согласованного расписания. Бэкенд сохраняет опубликованную копию в PostgreSQL, а сайт получает её через API.

Новая публикация заменяет предыдущую целиком и становится доступна после полного сохранения. Если приём или сохранение завершились ошибкой, сайт продолжает показывать предыдущую версию. Рассматривали обновление отдельных недель и частичную замену периода. Для MVP выбрали один способ обновления всей публикации, чтобы не объединять новую порцию занятий с прежней версией.
